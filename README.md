# 小学学习

面向小学阶段孩子和家长的英语、数学练习应用。本次已实现二年级双科首版：围绕学校当前主题安排长期学习，保留原有英语词库、诊断和口算能力。项目为纯前端单页应用，学习数据保存在当前浏览器，无需后端服务。

## 当前功能

- 首页以今日任务为主，支持年级、学期、英语当前单元、数学知识点、学习日及双科总时长设置；英语各单元可直接学习。
- 学期任务不受六周限制，区分未开始、休息和已结束；开始后的今日任务保持稳定，改课从后续日期生效。
- 保留一至六年级词库、单词卡、例句、对话、语速选择、六类词汇练习、诊断、掌握度与到期复习。
- 二年级 138 条词条和例句完成首轮模型语言检查，更新 11 单元对话；新增家庭、食物、课堂三个情景练习。词汇与情景练习按实际题型记录听辨、认读、拼写及可选家长表达确认，语音失败可切换文字题。
- 数学提供五项百以内加减专项与三项乘法专项，含阵列图、解题提示和换数字重练。日常专项不限时，20 题快速练和 100 题整卷作为挑战，专项成绩按知识点区分。
- 数学和新增英语情景练习支持同标签页草稿恢复；练习暂停与计时挑战采用不同计时规则。
- 双科周报区分实际练习、技能证据与计划执行情况，依据已记录的设置历史统计缺席日，不把未来日期提前计为未完成。
- 设置页可导出英语、数学、设置三类数据，校验备份后恢复；恢复前下载旧备份。存储写入失败显示提示并暂存在当前页面，重置可选择是否保留设置。

## 使用边界

内容为通用主题和能力练习，尚未与孩子实际教材逐章对应；学期与教材备注不代表教材同步。首轮内容检查未经教师或母语者复核。数学尚未覆盖长度、时间、图形、除法和系统生活应用题。

没有账号、云同步、多设备自动同步、自动口语评分或完整离线支持。语音依赖浏览器能力，未实现离线音频或 PWA。每日约 10/15/20 分钟是配额设计目标，孩子实际设备验收及两周试用仍待完成。

## 本地开发与检查

技术栈：React 19、TypeScript 5、Vite 8、React Router 7、Tailwind CSS 4、Framer Motion、Vitest。

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`。提交前运行：

```bash
npm test
npm run lint
npm run build
```

测试覆盖存储迁移与异常、备份恢复、日期和计划历史、任务完成归属、英语技能证据及草稿、数学题目和计时、周报与内容结构。仍需手动验证实际浏览器中的音频、触控、导航和响应式布局。

```bash
npm run preview
```

构建产物位于 `dist/`。应用使用 Hash Router，可部署到静态托管服务；本次开发完成不代表已经发布。

## 数据与文档

| 存储位置 | 内容 |
|---|---|
| `localStorage: english_app_data` | 英语进度、掌握度、诊断、每日计划、设置历史与技能证据 |
| `localStorage: english_app_math_data` | 数学成绩、历史、知识点进度和错题 |
| `localStorage: english_app_settings` | 语速、学期计划及课程备注 |
| `sessionStorage` | 数学与新增英语情景练习草稿 |

数学练习历史、英语学习会话及技能证据按最近 180 天保留；不代表所有累计进度都会到期删除。JSON 备份包含三类持久数据，不包含未完成草稿。清理浏览器或换设备前请下载备份；写入失败时请先导出，避免关闭页面丢失内存中的最新记录。
